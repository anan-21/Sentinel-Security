# 覆盖范围

- 当前工具、宿主配置、某次只读测试和历史记录是不同证据。单靠工具名称无法判断实际 OAuth scopes、已访问网站或全部历史账号，复合工具的精细权限尤其需要验证。
- 自定义别名或未识别服务可通过 host 观察项中的 service/category 显式标注。操作分类是基于命名的线索。新宿主或未知清单格式返回待确认。
- 静态规则会将教育材料中引用的攻击标记为风险，也会漏掉语义改写、其他语言或多层编码攻击。LOW 不构成安全保证；名片、显示名和相似域名无法验证发件人身份。当前不接威胁情报，不输出 CRITICAL。
- 提示词检测只针对传入字段；规则无法在所有宿主上保证“模型首次看到内容之前”的拦截。自由文本动作仅支持明确的只读目标冲突识别，其余语义不能完全验证。结构化动作评估需要宿主给出可信的任务来源。
- 定时任务与主动通知取决于对应账户、后台调度、只读连接器和通知目的地。尚无对真实私人邮箱、WhatsApp 或生产消息投递的验收。没有验证的宿主按需使用。
- WorkBuddy 已验证本机网易邮箱配置的发现和复用；第三方邮件助手已完成单账户 IMAP 登录验证，但还没有“真实新邮件 → Sentinel 扫描 → 自动告警”的验收。Muse 云端 HTTPS 接入和 Windows 安装仍待验证。CodeBuddy CLI 钩子的结果不能外推至 WorkBuddy 图形界面的所有路径。
- 邮箱初始化目前自动配置网易系列，且依赖 WorkBuddy 市场的「163邮箱助手」及当前审核过的版本。助手缺失时需宿主有原生安装能力；没有此接口就报告安装入口。仅索引 Skill 文件不会执行初始化；本机脚本被禁用时无法自动打开向导。其他邮箱继续使用宿主自己的真实授权入口。
