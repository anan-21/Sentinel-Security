# 安全与隐私
无网络抓取、DNS解析、附件执行、邮箱凭据或持久化正文。URL 包含私网地址仅返回风险，不探测。鉴权在 MCP 路由外层，常量时间比较；拒绝浏览器 Origin；限制输入大小；SDK Host 校验。日志仅记录耗时，不记录输入、token、证据。报告原文证据仍属敏感数据，调用者必须保护。

单用户单实例；不同用户部署不同实例和 token。TLS 在反向代理终止，正式部署需限流。应用异常由框架返回协议错误；不得把调试堆栈或正文发布给公共访问者。健康接口公开且不暴露配置。

规则输入永不执行。不保证语义识别或全局拦截。涉及敏感行动必须继续经过 Muse 原生权限控制。服务无后台状态；游标和通知去重是 Muse 初始化方案，未被本服务器执行。停止容器即停止服务；同时在 Muse 取消任务和撤销 Connector。
