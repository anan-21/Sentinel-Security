# 安全与隐私

**输入与权限。** 所有扫描规则在本地执行；输入文本、提取的 URL 以及命中证据都不作为命令。服务不拉取网址、解析 DNS 或执行附件。远程传入的内容会到达用户指定的服务器，转发前应脱敏。URL 证据只回传位置，避免将 query 中的令牌复制进告警。文本命中与网址重叠、包含可识别的凭据赋值或超过 256 字符时，也只给出原文位置。其他文本证据仍可能包含私人内容，通知应限制接收人和长度。

**发现。** 仅处理选定宿主的连接元数据。OpenClaw 的 chat 信息不提供邮箱内容权限。WorkBuddy 档案由调用方选择，v4 文件中的授权覆盖字段不参与分析，不解密或查找密钥。DSH 需要 Agent 作用域。过去绑定的记录只有在宿主保留或用户选择了本地历史时才可见。网站登录 cookie、浏览历史和其他账户不是发现来源。

**工具控制。** 源端必须提供真实任务授权和操作来源；模型或外部正文自行宣称的 approval 无效。MCP 决策结果是建议。可选宿主钩子使用宿主身份和管理员允许清单，默认不开启全局限制。允许一个复合工具可能允许其全部功能，监控清单应限于专用只读工具，尤其不要放入通用 shell、HTTP、代理委派或可写 MCP。无宿主钩子时不承诺强制拦截。

**存储。** 扫描服务不保存正文。CLI 的 --remember 仅保存宿主、用户指定的配置别名、已配置的服务标识；数据库位于 XDG_STATE_HOME 或 ~/.local/state 下的 sentinel-security 目录，默认关闭。更换账户需更换别名。调用方自己控制会话和日志留存。

**部署。** stdio 使用本地进程边界。HTTP 使用单用户实例和随机 Bearer token，校验 Host，拒绝浏览器 Origin，限制请求体为 256 KiB。公网前置 TLS、超时和限流，关闭代理的请求体、认证头及查询参数日志。健康端点只说明进程可达。每个用户使用自己的实例和令牌。
